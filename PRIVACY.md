# Privacy Policy – SLUSHE Discord Bot

**Last Updated:** August 10, 2026

This Privacy Policy explains how **SLUSHE** ("Bot") collects, uses, and protects user data.

## 1. Data We Collect
SLUSHE only processes data necessary for its operational functionality:
* **User IDs & Server (Guild) IDs:** Used to process commands, store settings, and manage configurations.
* **Command Usage:** Temporary logs of command executions for debugging and performance optimization.

We **do not** log or store personal message content, IP addresses, or real identity information.

## 2. How We Use Data
Collected data is exclusively used to:
* Provide and execute Bot commands and features.
* Save server-specific configurations.
* Maintain service security and stability.

## 3. Data Sharing & Third Parties
No data collected by SLUSHE is sold, shared, or transferred to third parties.

## 4. Data Retention & Deletion
* Server configuration data is stored as long as the Bot remains in your server.
* You can request total deletion of stored data related to your server/user by removing the Bot or contacting the developer via Discord/GitHub.

## 5. Contact
If you have questions regarding this Privacy Policy, please reach out via our GitHub repository.
